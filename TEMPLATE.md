# Происхождение шаблона

Оформление взято из [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex), версия `7b16e2c99fc8e0eab64be02f10fd2077c956dc6f`.

- `misisarticle.cls` скопирован без изменений. Автор: sadekovlar, 2026. Лицензия класса: LPPL 1.3c или более поздняя; полный текст находится в `LICENSES/LPPL-1.3c.txt`.
- `article.tex` основан на структуре шаблона, демонстрационный текст заменён черновиком статьи о калибровке ToF-камер. Метаданные и разделы вынесены в отдельные файлы.
- `Makefile`, `.gitignore` и workflow GitHub Actions адаптированы для одной статьи и архива Overleaf. Сборка демонстрационной статьи удалена, добавлен ручной запуск и явно ограничены разрешения workflow.
- Исходный неизменённый шаблон доступен по указанной ссылке и коммиту. Его автор не является автором текста этой статьи и не отвечает за её содержание.

Файл `LICENSE` — исходная лицензия LPPL 1.3c шаблона; он сохранён без изменений. Её копия также находится в `LICENSES/LPPL-1.3c.txt`.
