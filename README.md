# Внешняя калибровка нескольких ToF-камер

[![Сборка PDF](https://github.com/beastcris/tof-calibration-article/actions/workflows/build.yml/badge.svg)](https://github.com/beastcris/tof-calibration-article/actions/workflows/build.yml)

Репозиторий научно-исследовательской работы. **Текущая версия — первый черновик статьи: постановка задачи и предполагаемый метод.** Алгоритм ещё не реализован, экспериментальных результатов нет.

**Автор:** Бауэр Вольдемар Владимирович, БПМ-23-ПО-1.

**Научный руководитель:** Мишуров С. С.

Рабочая тема: «Внешняя калибровка нескольких ToF-камер с использованием калибровочного объекта». Формулировку нужно согласовать с научным руководителем.

Оформление основано на [шаблоне sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex). Сведения об исходной версии и лицензии — в [TEMPLATE.md](TEMPLATE.md).

Каталог `example/` и `CHANGELOG.md` сохранены из исходного шаблона. В `example/` находится образец его оформления, а не статья автора этой НИР; в автоматическую сборку он не входит.

## Содержание статьи

1. Введение: задача объединения наблюдений нескольких камер и цель исследования.
2. Анализ работ: калибровка, EPnP, маркеры, совместная оптимизация, особенности ToF и ICP.
3. Постановка задачи: системы координат, входные данные, искомые параметры и условия определимости.
4. Описание предполагаемого метода: начальная оценка по изображениям, совместное уточнение и возможное добавление глубины.
5. Литература: восемь научных источников.

Разделы «Эксперимент» и «Заключение» пока отсутствуют. В разделе методов описан план проверки, а не полученные результаты. Модели камер, формат данных и геометрия мишени пока не установлены; конкретные характеристики не выдумываются.

## Где скачать PDF

После отправки изменений GitHub Actions собирает статью автоматически:

1. Откройте [Actions → Build article PDF](https://github.com/beastcris/tof-calibration-article/actions/workflows/build.yml).
2. Выберите успешный запуск для нужного коммита.
3. В разделе **Artifacts** скачайте `article.pdf`.

Сборку также можно запустить кнопкой **Run workflow**. В форке GitHub может потребоваться сначала включить Actions. Для скачивания артефактов требуется вход в GitHub; срок хранения — 30 дней. При необходимости PDF можно пересобрать.

## Локальная сборка

Нужны [Tectonic 0.17.0](https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0) и `make`. При первом запуске Tectonic загружает пакеты TeX, поэтому требуется сеть.

```sh
make article
# Результат: build/article.pdf
```

Для другого пути к компилятору: `make article LATEX=/path/to/tectonic`.

Для оформления как в CI нужны **Times New Roman** и **Courier New**. В GitHub Actions используется Windows с проверкой наличия этих шрифтов. Без них класс выбирает запасной шрифт, и переносы строк могут отличаться.

## Overleaf


## Что уточнить для следующей версии

- Утверждённую тему, аффилиацию, email и требуемые классификационные коды.
- Количество и модели камер, доступные каналы и пример записи.
- Внутренние параметры, дисторсию, единицы и смысл глубины: осевая координата или дальность по лучу.
- Форму и точные размеры объекта, тип меток, их координаты и точность изготовления.
- Схему размещения камер, синхронизацию и порядок съёмки мишени.
- Наличие независимого эталона или возможности отдельно проверить качество калибровки.

После получения данных следует проверить применимость описанной схемы, реализовать базовый вариант и только затем дополнять статью результатами и выводами.
